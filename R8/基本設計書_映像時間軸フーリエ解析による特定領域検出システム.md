# 基本設計書

## 映像時間軸フーリエ解析による特定領域検出システム

### 1. システム概要

#### 1.1 目的
ディスプレイ上の特定領域で発生している「特定の周波数(Hz)の点滅変化」を、スマホ等で撮影した動画から検出し、その領域(座標)を視覚的に自動抽出する。

出力は主に以下とする。

- 点滅領域のヒートマップ画像
- 二値化されたマスク画像
- 必要に応じたスコアマップ

#### 1.2 処理の原理
動画を「時間軸」「縦」「横」の3次元データとして捉え、全ピクセルに対して時間方向の1次元離散フーリエ変換(1D DFT)を適用する。

これにより、背景などの静止・不規則変化成分を抑え、指定した周波数で同期点滅しているピクセルのみを高感度に抽出する。

### 2. 前提条件および入力データ要件

#### 2.1 撮影・入力データ要件

| 項目 | 要件 | 仕様 | 備考 |
| --- | --- | --- | --- |
| 動画フォーマット | MP4 または AVI | OpenCVでデコード可能であること |  |
| 撮影フレームレート ($f_s$) | 固定 | 例: 60 fps | 可変フレームレート(VFR)は不可 |
| シャッタースピード | 1/250秒以下を推奨 |  | 点滅のブレ(モーションブラー)を防ぐため |

#### 2.2 ディスプレイ(ターゲット)側要件

- 点滅周波数($F$)は、スマホ撮影フレームレートの半分未満とする。
- ナイキスト周波数の条件は $F < \frac{f_s}{2}$ とする。
- 例: 60fpsで撮影する場合、点滅は30Hz未満とし、10Hz〜20Hz付近を推奨する。

### 3. 全体処理フロー

```text
[入力動画ファイル]
       │
       ▼
【モジュール1: 動画読み込み・前処理】 ───> 3次元配列化、輝度化、DC成分除去
       │
       ▼
【モジュール2: 時間軸1次元FFT】     ───> SciPyによる並列周波数解析
       │
       ▼
【モジュール3: 周波数抽出・判定】   ───> ターゲット周波数のパワー抽出、S/N比計算
       │
       ▼
【モジュール4: 可視化・出力】       ───> ヒートマップ表示、二値化マスク出力
```

### 4. 各モジュールの詳細設計

#### 4.1 モジュール1: 動画読み込みと前処理

**処理内容**

- 動画ファイルをオープンし、メタデータからフレームレート(FPS)と総フレーム数($N$)を取得する。
- 全フレームをループで読み込み、グレースケール(輝度)画像に変換する。
- データを浮動小数点型(float32)の3次元配列 $[N, Height, Width]$ に格納する。

**トレンド除去(DC成分カット)**

時間軸方向(axis=0)の平均値を計算し、各ピクセルから引く。

$$
\text{Data}_{\text{detrend}}(t, y, x) = \text{Data}(t, y, x) - \frac{1}{N}\sum_{t=0}^{N-1}\text{Data}(t, y, x)
$$

**オプション**

- 時間軸方向に窓関数(Hanning窓等)を乗算し、周波数リーケージを抑制する。

#### 4.2 モジュール2: 時間軸1次元FFT

**処理内容**

- 前処理済みの3次元配列に対し、時間軸(axis=0)に対して1次元高速フーリエ変換(FFT)を実行する。
- 使用ライブラリは scipy.fft.fft とし、引数 workers=-1 を指定してマルチコア並列処理を行う。
- 計算結果から、正の周波数成分に対応する前半部分(0 から $\frac{N}{2}$ まで)を抽出する。
- 複素数データから絶対値(np.abs)を取り、振幅(パワー)スペクトル配列 $[N//2, Height, Width]$ を得る。
- scipy.fft.fftfreq を用いて、各インデックスに対応する実際の周波数(Hz)の配列を生成する。

#### 4.3 モジュール3: ターゲット周波数の特定とスコアリング

**処理内容**

- 周波数配列から、ディスプレイの設定周波数($F$ Hz)に最も近いインデックス(target_idx)を特定する。
- 該当インデックスにおける2次元の振幅マップ $[Height, Width]$ を抽出する。

**判定スコア(S/N比)の計算**

単なる絶対的な振幅値だと、周囲の環境光やノイズの影響を受けるため、以下のスコア値をピクセルごとに計算する。

$$
\text{Score}(y, x) = \frac{\text{Amplitude}(target\_idx, y, x)}{\text{Mean}(\text{Amplitude}(all, y, x))}
$$

これは、ターゲット周波数の振幅が、そのピクセルの平均的なノイズ振幅に対して何倍突出しているかを表す。

#### 4.4 モジュール4: 可視化と領域出力

**処理内容**

- スコアマップ、または振幅マップを 0〜255 または 0〜1 に正規化する。
- matplotlib のカラーマップ('hot' や 'jet')を適用し、点滅領域が明るく発光するヒートマップ画像を作成・保存する。
- 閾値(Threshold)を設定し、スコアが閾値以上のピクセルを 255(白)、それ以外を 0(黒) とする二値化マスク画像を生成する。

### 5. 考慮すべき課題と対策

#### 5.1 周波数のミスマッチ対策

カメラの実際のFPSと公称値(例: 59.94fpsと60fps)のズレにより、ターゲット周波数のインデックスが前後に1セルずれる可能性がある。

そのため、target_idx の前後1セルも含めた最大値(np.max)を抽出する処理を検討する。

#### 5.2 メモリ対策

動画が長すぎると(数千フレーム以上)、3次元配列がメモリ(RAM)を圧迫する。

実験時は3〜5秒(180〜300フレーム程度)の短い動画でクリップして処理するロジックを前処理に挟む。

### 6. 実装上の補足

- 解析対象は「時間方向の周期性」であるため、空間的な位置ずれには比較的頑健だが、動画内で対象領域が大きく動く場合は検出精度が低下する。
- ノイズが強い場合は、前処理で平滑化やROI制限を追加する。
- 実装では、FFT結果の周波数軸と target_idx の対応を明示的に管理する。
- 出力ファイルは、解析用の中間結果と最終結果を分けて保存する。

### 7. 想定出力

- 入力動画の基本情報(FPS、フレーム数、解析時間)
- ターゲット周波数のスペクトルマップ
- スコアマップのヒートマップ画像
- 二値化マスク画像
- 必要に応じた検出領域の座標情報

### 8. まとめ

本設計は、動画を時間軸上の信号として扱い、全ピクセルへ並列な1次元FFTを適用することで、特定周波数で点滅する領域を高感度に抽出することを目的とする。

この基本設計書により、開発AIは必要な数式、NumPy/SciPyの軸指定(axis=0)、並列化(workers=-1)、および周波数判定の考え方を一貫して理解できる。
